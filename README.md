# Educa+ 🎓

Sistema de gestão escolar desenvolvido como projeto acadêmico.

## 🌐 Como acessar

**Site hospedado:** acesse o link do Educa+ disponibilizado pela equipe.

## 💻 Como executar localmente

1. Abra a pasta do projeto no Visual Studio Code.
2. Instale a extensão **Live Server**.
3. Abra o arquivo `index.html`.
4. Clique com o botão direito e selecione **Open with Live Server**.

## ⚙️ Por que utilizar o Live Server?

O Educa+ utiliza módulos JavaScript e integração com Firebase Authentication e Firestore, que precisam ser executados em um servidor web.

O Live Server cria um servidor local para executar o sistema corretamente. Também é possível acessar o projeto pelo link hospedado, sem precisar instalar ou configurar nada.

**Importante:** não abra o `index.html` diretamente pelo computador (`file://`), pois algumas funcionalidades podem não funcionar.

## 🛠️ Tecnologias

* HTML, CSS e JavaScript
* Firebase Authentication
* Firebase Firestore
